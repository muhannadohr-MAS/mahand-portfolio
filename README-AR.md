# مهند سلامة — نسخة Vercel

فك الضغط وارفع مجلد المشروع كاملاً، وليس ZIP كملف صفحة. أو ارفع المحتويات لمستودع GitHub واربطه بـ Connect Git.

Framework: Next.js. Build: npm run build. Output Directory: الافتراضي.

أضف متغيرات البيئة الموضحة في .env.example عبر Vercel > Environment Variables. القيم السرية غير مضمنة عمداً. مفتاح SUPABASE_PORTFOLIO_BRIDGE_KEY يجب أن يطابق مفتاح الموقع الحالي؛ بدونه لا يعمل الاتصال بالبيانات. لا تستخدم service_role في الواجهة.

قاعدة البيانات والمرفقات تبقى في Supabase ولا تحتاج نقلها.

لوحة الإدارة: /admin. استخدم بريد muhannad.ohr@gmail.com وكلمة المرور التي أعددتها على الموقع الحالي. إن لم تعدّ كلمة المرور بعد، أكمل الإعداد أولاً من لوحة الإدارة بالموقع الحالي الخاص. تهيئة هوية ChatGPT لا تعمل على Vercel وتم تعطيلها بأمان.

فعّل Deployment Protection قبل رفع أي نسخة للمحافظة على الخصوصية. لا تربط الدومين حتى ينجح اختبار المعاينة وتوافق على الإتاحة.
